# KitsuneMaskOnWSALocal

A fork of [MagiskOnWSALocal](https://github.com/LSPosed/MagiskOnWSALocal) with
extra root methods:

- Magisk variants: **Kitsune Mask** and **Magisk Alpha** (prebuilt APKs in [`apks/`](apks))
- Root solutions: **KernelSU**, **SuKiSU-Ultra** and **APatch** in addition to Magisk

## Usage

```bash
git clone https://github.com/pen-pig/KitsuneMaskOnWSALocal.git --depth 1
cd KitsuneMaskOnWSALocal
./scripts/run.sh
```
